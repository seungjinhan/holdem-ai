# holdem-ai

Web No-Limit Texas Hold'em: one human vs 1–5 AI opponents, virtual chips only (phase 1).

- Starting chips 1,000 · blinds 5/10 · up to 5 AI
- Pure, event-sourced game engine (no DOM/browser dependency) so phase 2 multiplayer can reuse it
- Static site hosted on GitHub Pages

Work in progress — see open pull requests.
